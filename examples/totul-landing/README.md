# Totul landing (RU/RO)

Профессиональная адаптивная HTML/CSS/JS вёрстка с переключением языка (русский/румынский).

## Что внутри

- `index.html` — структура сайта.
- `assets/styles.css` — адаптивные стили (desktop/tablet/mobile).
- `assets/script.js` — перевод RU/RO, сохранение языка в `localStorage`, мобильное меню.

## Локальный запуск

Откройте `examples/totul-landing/index.html` в браузере.

## Архив для отправки клиенту

```bash
zip -r totul-landing.zip examples/totul-landing
```

После выполнения вы получите архив `totul-landing.zip`.
